# Linear-Regression-Model-Fastapi-

by t2hasnain.me

This project serves a **Linear Regression** model using **FastAPI**.

## Project details
- Model file: `model.pkl`
- Framework: FastAPI
- Dataset: Weight-Height-Gender dataset
- Training data size: 10,000 rows (10k)
- Main columns used for training: `Gender`, `Height`, and `Weight`

## What this API does
- Loads the trained `model.pkl` model
- Accepts input features from the Weight-Height-Gender schema
- Returns linear regression predictions through FastAPI endpoints
